# Cadastro AC Hisense

App para o time comercial gerar as fichas de cadastro dos clientes (Excel) e a ficha técnica Hisense (PDF) a partir da base de produtos de ar-condicionado.

## Como atualizar

**Base de produtos**
1. Abra o site, vá em *Atualizar base* e suba a planilha nova (aba *Infos AC_Hisense*).
2. O app baixa um arquivo `base.json`.
3. Aqui no GitHub: *Add file → Upload files*, arraste o `base.json` e clique em *Commit changes*.
4. Em 1 ou 2 minutos o site já usa a base nova.

**Logo**
Suba a imagem do logo com o nome `logo.png` pelo mesmo caminho (*Add file → Upload files*).

**Modelos dos clientes**
Os formulários de cada cliente ficam na pasta `tpl/`. Para trocar um modelo, peça a versão nova convertida.
